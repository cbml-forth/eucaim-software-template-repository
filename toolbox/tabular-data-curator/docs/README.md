## Summary

The Tabular Data Curation (TDC) tool evaluates the quality of a tabular dataset (e.g. clinical or
imaging metadata) and produces curated versions of it. It reports feature-level diagnostics
(missing values, type inconsistencies, outliers), highlights problematic fields, removes low
quality features, and detects highly correlated and lexically similar pairs of features.
